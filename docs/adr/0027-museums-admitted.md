# ADR-0027：觀光景點資料集只收博物館，並將 museum 加入豁免清單

- **狀態**：已採納
- **日期**：2026-09-02
- **相關**：[ADR-0019](0019-per-row-admission-test-northern-taiwan.md)、[ADR-0020](0020-library-admitted-on-category.md)

## 背景

覆蓋率診斷長期紅燈，缺口一直指向同一件事：**室內選項只有圖書館一種**。
資料庫十一個類別只有三個有資料。

使用者問「如何讓推薦點更加全面」，而直覺的答案（多匯一點）是錯的：
**診斷的停止條件是「類別 ≥ 3」，不是筆數。** 匯入新北 635 個公園會讓
總數從 1405 變成 2040，但公園這個類別本來就有 684 個——**對紅燈的貢獻是零**。

## 抓下來看到的事實（2026-09-02）

資料集 7777「景點－觀光資訊資料庫」，全國 6189 筆、每日更新、
`PositionLat/Lon` 100% 有值（不需要 geocoding）。

但它撐不起入場測試：

| 欄位 | 填充率 |
|---|---|
| `VisitDuration` | **2%**（全國 177 筆） |
| `Facilities` | 1% |
| `LocatedCities` | **0%**（所以用 `PostalAddress.City` 篩） |

`AttractionClasses` 雖然 100% 有值，但語意是髒的。北部最大的代碼 12
（671 筆）同時包含「橘之鄉蜜餞形象館、休閒養殖場、精雕藝術館、
五峰旗風景區、跑馬古道、溫泉廣場、瀑布、石磐步道」——**不能拿來映射類別**。

改用名稱關鍵字分類，北部四縣市 1341 筆裡只認得出 15%：

| | 筆數 | 判斷 |
|---|---|---|
| `trail` 步道 | 107 | ❌ 對幼兒多半過不了適齡與家長負擔 |
| `museum` 博物館 | **87** | ✅ 室內、有冷氣、放電低 |
| `farm` 農場 | 18 | ❌ 量太少 |
| `beach` 海邊 | **4** | ❌ 量太少 |

## 判準第 2 條的前提已被量測推翻

ADR-0020 的豁免判準第 2 條寫著：

> **移除該類別會在推薦輸出上造成結構性空缺。**
> 第 2 條是真正的守門者。農場、步道、海邊都講得出一套「Google 分不到
> 這個粒度」的說法，但**少了它們，三個槽位照樣填得滿**。

**最後那句已經不成立。** 寫的時候是假設三個槽位填得滿；覆蓋率診斷實測
五個情境有三個填不滿。所以判準第 2 條現在是**支持**再放類別進來的理由。

但仍要逐個看證據——這正是步道 107 筆沒有一起放行的原因：
**講得出粒度理由不等於填得上空缺。**

## 決定

1. 寫一個只收博物館的 adapter，用名稱關鍵字（`博物館|美術館|科教館|
   科學館|故事館|紀念館|文物館`），範圍限北部四縣市（用 `PostalAddress.City`）
2. `museum` 加入 `CATEGORIES_ADMITTED_ON_THEIR_OWN`（第四項）
3. `VisitDuration` 有值時作為 `source_data` 進 `observed`，蓋掉類別先驗
4. **步道、農場、海邊不收。** 不是忘了，是量測後判斷投入產出比太差

## 結果

匯入 87 筆後重跑診斷：

```
          之前              現在
晴天上午   類別 3 ✓    →    類別 4 ✓
午後雷雨   類別 1 ⚠    →    類別 2 ⚠
酷暑       類別 2 ⚠    →    類別 3 ✓
連假       類別 3 ✓    →    類別 4 ✓
家長疲勞   類別 2 ⚠    →    類別 3 ✓
```

**五個情境從三個未達標變成一個。** 酷暑與家長疲勞轉綠的原因相同：
博物館室內、有冷氣、家長負擔 1，正好是那兩個情境剔除公園之後缺的那一格。

午後雷雨仍差一個類別——雨天只有圖書館與博物館存活。缺的是親子館
（201 筆等 TGOS 座標）或室內遊樂場（需 Google Places，需求補充 01 §A）。

## 附帶產物：最小的 ZIP 讀取器

這個資料集只提供 zip，而 `downloadText` 只處理文字。寫了 `lib/import/zip.ts`
而不是引依賴——ZIP 需要的只有「找中央目錄」與「對單一項目做 DEFLATE」，
而 Node 內建的 `zlib` 已提供後者。同 c4eb02b 對 CSV 解析器的判斷：
**為 60 行函式引入依賴，對一個要離線跑在 NAS 上的專案不划算。**

不支援加密、多磁碟、ZIP64。遇到會丟錯而不是靜默回錯的值。

## 什麼情況下該重新考慮

若哪天步道或海邊有了更好的來源（帶適齡、遮蔭、停車等實值），
它們就不再是「只有名稱與座標」，屆時可循 ADR-0019 的第 1 條入場，
不需要動豁免清單。
