# ADR-0013：基準車程改為自算的幾何估計，匯入階段不呼叫 Google

- **狀態**：已採納
- **日期**：2026-08-25
- **相關**：設計架構書 v1.0 §6.2、§7.1、§10.3、§11.2
- **取代**：[ADR-0009](0009-import-radius-not-counties.md) 中「匯入時對半徑內地點批次計算基準車程」的做法
  （半徑篩選本身仍然有效）

## 背景

ADR-0009 決定匯入全臺資料、只對住家直線半徑內的地點計算基準車程。
當時假設基準車程來自 Google Routes API 並長期儲存——
這正是 v1.0 §10.3 自己標記的「待確認事項」。

查證結果：**Google Maps Platform 服務條款允許暫存 distance、duration、time
與 ETA 值最多 30 個連續日曆日，之後必須刪除。** `place_id` 是唯一豁免項。

因此「匯入時算一次、永久存著當基準」不合規。

## 基準車程實際上被用在哪裡（先釐清，因為容易誤解）

討論過程中出現過一個誤解，值得寫進來：
「決策當下都用 Google 即時路況，長存的資料只有離線模式才需要」。

**這個理解是錯的，而且錯的方向會讓人低估這個估計的重要性。**

§7.1 的兩段式分工：

| 階段 | 對象 | 用什麼 |
|------|------|--------|
| 粗篩 | **全部地點**（可能數百筆） | **基準車程 × 日型係數** |
| 精算 | 僅存活的前 8 名 | Google 即時路況 |

所以基準車程有三個用途，離線只是其中最少見的一個：

1. **每次決策時粗篩全部地點** — 主力用途
2. **決定誰進得了「前 8 名」** — 幾何估計算錯的地點，Google 根本沒機會看到它，
   它在粗篩就被無聲剔除
3. API 失敗或離線時的降級（P9）

沒有它，每次決策都要對數百個地點呼叫 Google，額度很快用盡。
**它正是讓兩段式估算付得起錢的那個機制。**

## 被考慮的選項

### 選項 A：儲存 Google 的值，加 30 天有效期並定期重算
- 優點：粗篩用的是真實駕駛時間，準確
- 缺點：需實作過期、刪除與重算排程；每 30 天固定消耗數百次 API 額度，
  而這些呼叫全部花在「只是要粗篩」這件事上

### 選項 B：用地點座標自行計算幾何估計，匯入階段完全不碰 Google
- 優點：**沒有 ToS 問題**——座標來自政府開放資料，不是 Google；
  匯入階段零 API 呼叫，匯入器可離線執行；不需要過期機制
- 缺點：翻山、跨河、需繞行的路線會低估
  （板橋到宜蘭直線約 41 km，實際須經雪隧）

## 決定

選 **B**，由使用者於 2026-08-25 確認。

關鍵理由：**粗篩本來就是粗的。** §6.2 說基準車程「僅供粗篩，不呈現給使用者」，
§7.1 說粗篩門檻要「放寬約 20%，避免粗估誤差誤殺」。
既然規格本身就假設它不準且刻意留了緩衝，就沒有理由為它付出 API 成本與合規負擔。

### 誤差要刻意偏向低估

低估與高估的後果不對稱：

- **低估** → 地點通過粗篩 → 進入精算被 Google 真正檢查 → 若真的太遠會在那時剔除。**代價僅是多一點精算額度。**
- **高估** → 地點在粗篩就被剔除 → **永遠不會被重新檢視，而且沒有任何跡象。**

因此繞路係數應取保守（偏小）的值，寧可讓太多地點通過粗篩。
這與 §7.1「放寬 20%」是同一個意圖的兩種表達。

### 精算不受影響

決策當下對前 8 名的即時路況查詢照舊使用 Routes API。
那是即時使用而非長期儲存；§10.3.3 要求的「同起訖點短時間內快取」也在 30 天內，合規。

## 後果

- 得到：匯入器不需要 Google 金鑰，可完全離線執行
- 得到：沒有過期與重算機制要維護
- 得到：ADR-0009 的半徑篩選變得更單純——它就是純粹的座標運算
- 放棄：粗篩的準確度。翻山路線會被低估，因此會有較多地點進入精算
- 資料模型上：基準車程**不是儲存的欄位**，而是由座標即時導出的值。
  Google 回傳的精算結果若要快取，必須帶時間戳並在 30 天內刪除

### 什麼情況下該重新考慮

1. 若實際使用發現精算的呼叫量過大（因為粗篩放行太多），
   應先調整繞路係數或半徑，**而不是回頭儲存 Google 的值**
2. 若出現「明明開得到卻從來沒被推薦」的地點，那是高估造成的無聲剔除，
   應調降繞路係數。判斷方式：手動查那個地點的實際車程，與幾何估計比較
3. 若 Google 修改條款允許長期儲存，選項 A 才重新具備可比性
