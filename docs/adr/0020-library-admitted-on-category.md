# ADR-0020：圖書館加入類別豁免清單，並改寫該清單的判準

- **狀態**：已採納
- **日期**：2026-08-29
- **相關**：設計架構書 v1.0 §7.3、§7.4、§11.1
- **修改**：[ADR-0019](0019-per-row-admission-test-northern-taiwan.md) 入場測試第 2 條的清單內容

## 背景

ADR-0019 的入場測試第 2 條（「類別本身即為強資訊」）刻意寫成只有兩項的列舉，
並附了一句警告：「清單一旦開始成長，入場測試就名存實亡。」

2026-08-29 匯入臺北市公園 789 筆之後，第一次用真實資料跑推薦引擎，
結果暴露了一個那句警告沒有預見的問題：

```
室內外分布   outdoor: 789    indoor: 0
有冷氣       0
類別         inclusive_playground: 105 · park: 684
```

**§7.3 規定輸出固定三項，但只跑得出一項。** 不是 Stage 3 壞了，是沒有牌：

- 「備案 —— **至少一個室內選項**，供天氣突變」：一個室內地點都沒有
- 「前三名不得為同一類別」：只有兩個類別

而當天體感 38°C，引擎正確地把偏好權重歸零、加上補水警示，
然後拿不出任何有冷氣的地方。

這正是 §7.4 明文警告過的失效：

> 偏好學習會持續壓低不偏好的類別，使得雨天——正是最需要室內選項的時刻——
> 系統手上只剩品質最差、從未驗證的牌。

差別是入場測試讓它**提前發生在匯入階段**，而且更絕對：
不是「只剩最差的牌」，是一張牌都沒有。

而按 ADR-0019 的規則，這個狀況不會自己好轉：圖書館資料集（99567，616 筆、
全國、全部有座標）的欄位只有名稱、地址、電話、經緯度、簡介，
**616 筆會全數被入場測試擋掉**。親子館雖然在清單裡，但它缺座標，
要等 TGOS 那一步。所以室內選項會變成最後才有的東西，
而它是雨天與高溫時唯一有用的東西。

## 被考慮的選項

### 選項 A：維持清單只有兩項，先做 geocoding 讓親子館進來
- 優點：ADR-0019 的約束一字未改
- 缺點：把「有沒有室內選項」綁在一個外部服務的整合進度上。
  而且親子館只有 201 筆、全國，北部四縣市 102 筆——
  以「至少一個室內備案」的需求而言太薄

### 選項 B：加一條「類別覆蓋率不足時放行」的動態規則
- 優點：不必改列舉，自動適應
- 缺點：**匯入結果會取決於匯入順序與當下資料庫狀態**，
  不再冪等，也無法用純函式測。這與 `upsert.ts` 好不容易守住的性質直接衝突

### 選項 C：把 `library` 加進清單，並把清單的判準寫清楚（採用）

## 決定

選 **C**，由使用者於 2026-08-29 確認。

讓 `parenting_center` 合格的理由是：**免費、室內、有冷氣、低放電，
而 Google 的分類告訴你那裡是什麼，不告訴你帶兩歲小孩去可不可行。**
這段話幾乎逐字適用於圖書館——`category-priors.ts` 給 library 的
`energyBurn: 1`、`parentEffort: 1`、`hasAirConditioning: true`、
`safetyEnclosure: 3` 正是雨天與高溫時最需要的組合。

所以問題不在於圖書館夠不夠格，在於 ADR-0019 把判準寫成了一份沒有理由的名單。

### 清單的判準（取代 ADR-0019 的「刻意只有兩項」）

一個類別可以列入豁免，必須同時滿足：

1. **該類別的先驗值組合本身就是強資訊**，且 Google 的分類到不了那個粒度
2. **移除該類別會在推薦輸出上造成結構性空缺**——
   也就是 §7.3 的三個槽位或 §7.4 的防同溫層會因此無法運作

第 2 條是這次補上的，也是真正的守門者。它把「感覺也算」擋在外面：
農場、步道、海邊都能講出一套「Google 分不到這個粒度」的說法，
但少了它們，三個槽位照樣填得滿。

清單現為三項：`parenting_center`、`inclusive_playground`、`library`。

## 後果

- **得到**：616 筆室內、有冷氣、低放電的地點，§7.3 的備案槽位有牌可出，
  探索槽有第三個類別可選
- **放棄**：ADR-0019「只有兩項」那個乾淨的約束。
  換來的是一條寫得出理由的判準——名單會長，但每一項都要說得出
  它填補的是哪一個結構性空缺
- **注意**：圖書館全部走類別豁免進來，代表它們的決策欄位**全部是先驗值**。
  在造訪紀錄累積之前，引擎分不出兩間圖書館的差別。
  這是接受的代價：有一張品質普通的牌，好過雨天沒有牌
- **何時重新考慮**：若清單成長到五項以上，代表第 2 條沒有發揮守門作用，
  屆時該檢討的是入場測試的整體設計，而不是再加一項
