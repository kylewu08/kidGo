# 開放資料來源盤點（2026-08-26 實測）

> **這份文件記錄的是事實不是決定。** 設計架構書 §10.1 對資料來源的描述有幾處
> 與現況不符，本文列出實際查證的結果，供「資料來源怎麼取」的討論使用。
>
> 尚未做完：全目錄的系統性重掃（見文末「已知的盤點缺口」）。

## 1. 抓取方法（可重現）

三步，全部不需要帳號：

```bash
# 1. 全平臺資料集總清單：53085 筆，66 MB，每日凌晨 1 時更新
curl -sSL "https://data.gov.tw/datasets/export/csv" -o catalog.csv

# 2. 單一資料集的 metadata（資料集編號穩定，下載網址會變）
curl -sS "https://data.gov.tw/api/v2/rest/dataset/128366"

# 3. 從 metadata 的 distribution[].resourceDownloadUrl 下載
curl -sSL "<resourceDownloadUrl>" -o out.json
```

### 兩個必須寫進匯入器的規則

1. **選資源要用 `resourceDescription` 比對，不可用陣列索引。**
   一個資料集編號底下可以掛多份語意不同的資源——`148726`「桃園市公園」
   有「埤塘公園」（10 筆）與「特色遊戲場」（45 筆）兩份 CSV。
   用索引會在資料集改版時無聲地換掉抓的內容，而且錯得很像對的。
2. **硬寫資料集編號，執行時查 metadata 取下載網址。**
   下載網址含 UUID（例：`data.ntpc.gov.tw/api/datasets/5fe3a136-…/csv/file`），
   會隨改版變動；資料集編號不會。

## 3. 設計架構書 §10.1 與現況的落差

| §10.1 的描述 | 實際 |
|---|---|
| 「各縣市兒童遊戲場清冊，法定登錄資料，品質最高，其**適用年齡**欄位可直接對應設施適齡層」 | **沒有全國清冊**，只有少數縣市有；且**沒有任何一份含適用年齡欄位** |
| 「親子館／托育資源中心，室內主力，雨天備案」 | 全國名冊存在，但**沒有座標** |
| 「公園設施，涵蓋面最廣」 | 沒有全國資料集，逐縣市且格式各異 |
| 「這些資料結構化、免費、**有座標**」 | 只有觀光景點、圖書館、臺北／臺中的公園遊戲場有座標 |

### 但 128366 補回了比預期更多的東西

臺北市公園基本資料的欄位遠超其他縣市：

| 欄位 | 有值 | 可推導 |
|---|---|---|
| `pm_Longitude` / `pm_Latitude` | 815 / 815 | 臺北的公園不需要 geocoding |
| `pm_playtype`（`一般` 329／`共融` 63／`特色` 42） | 434 | **直接對應 `Category`**，不必靠名稱關鍵字猜 |
| `pm_playeq`（遊具清單，如 `彈跳床,搖滾盤,攀爬組,磨石滑梯`） | 432 | `facilityAgeBands` |
| `pm_playarea`（遊戲場面積 m²） | 434 | **`runnableSpace` 的客觀依據，可標為非先驗值** |
| `pm_opening_stime` / `pm_opening_etime` | 815 | 營業時間 |
| `pm_type`（`公園` 607／`綠地` 179／`廣場` 29） | 815 | 綠地與廣場多半應排除 |

桃園的「設施」欄位也可規則式解析（45 筆中：溜滑梯 35、攀爬 32、鞦韆 25、
沙坑 19、低齡兒童遊具組 7、大齡兒童遊具組 2、共融 6）。

**結論**：§10.1 說的「適用年齡」欄位確實不存在，但**遊具清單與遊戲場面積**
可以規則式推導出適齡層與可奔跑空間，且是確定性、可測的。
代價是每個縣市一套欄位語彙對照表。

## 4. 座標缺口與三條補法

目前缺座標的共 **881 筆**：親子館 201、新北公園 635、桃園遊戲場 45。

新北 635 筆的地址品質實測：

| 型態 | 筆數 | |
|---|---|---|
| 純路名／描述（`光明路3巷`） | 288 | 45% |
| 路口（`文化路與長江路口`） | 135 | 21% |
| 有乾淨門牌號（`莊敬路179號`） | 111 | **17%** |
| `X號對面`／`X號旁` | 98 | 15% |

- **離線 join 門牌資料**（各縣市有「門牌位置數值資料」開放下載，新北 198 萬筆）：
  不需任何 API，但**只救得回 17%**——公園本來就常在路口、河濱、橋下
- **TGOS 全國門牌地址定位服務**：官方、免費、無快取期限。處理得了路口與純路名。
  **已於 2026-08-26 註冊**
- **Google Geocoding**：結果與 Routes 同受 30 天快取限制，**不可永久儲存**
  （即 ADR-0013 的理由），不適合當基準座標來源
- 桃園資料的 `地標` 欄位是 `goo.gl/maps` 短網址，302 目標網址直接帶座標
  （實測 `大有梯田生態公園 → 25.0125677, 121.3210802`）。免費且精準，
  但實質是抓 Google Maps（ToS 灰色地帶），且短網址在退場路上。
  **僅適合當交叉驗證，不宜當主力**

## 5. 已知的盤點缺口

**上述結論尚未經過系統性重掃，可能仍有遺漏。** 已知的一次：
`128366` 在第一輪就出現在篩選結果裡，但因為它的提供機關叫
「臺北市政府工務局公園路燈工程管理處」、資料量欄位空白，混在 20 筆
高雄「公園處路燈資訊」中被略過。

待做：以「欄位說明含經緯度」為主篩（而非「名稱含公園」），
對全目錄重掃一次，涵蓋公園、遊戲場、遊具、親子、兒童、遊憩等詞。
